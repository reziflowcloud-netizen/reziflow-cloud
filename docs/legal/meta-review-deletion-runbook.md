## Exact-target execution and proof

1. Stop the owned gateway/app/worker and owned DB using retained ownership/cluster markers; prove no matching listener or active endpoint remains. Do not terminate an unverified PID or another project's process.
2. Recheck canonical absolute targets against the private manifest, FILE/directory type, owner/strict ACL, no links and no unexpected contents. Produce a fresh read-only inventory and deletion preview. Existing specific approvals do not authorise deleting different paths.
3. Execute only the actually authorised exact targets, using one native shell end to end. Do not recursively delete an unchecked computed root, source checkout, `.git`, another project, Production backup or key.
4. Verify absence of each removed object and of owned active listeners/processes, then update a minimal non-secret outcome. If policy or ownership checks refuse, stop, preserve the refusal and report OPEN; no bypass or automatic deadline extension.
