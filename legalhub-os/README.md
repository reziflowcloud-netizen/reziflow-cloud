# LegalHub Marketing OS

LegalHub Marketing OS is a safe marketing memory layer for LegalHub CRM.
It lives only in `/legalhub-os/` and is designed so future Codex chats can
continue marketing, positioning, and content work without losing context or
touching application code.

Use it as the source of truth for marketing work:

- Start by reading `CURRENT_STATE.md`, `NEXT_STEPS.md`, and `TASK_LOG.md`.
- Use `PROJECT_BIBLE.md` for positioning, audience, problems, benefits, and
  open questions.
- Use `PRODUCT_MAP.md` for the product structure, modules, routes, features,
  roles, processes, and visible data entities.
- Keep all marketing notes, drafts, and future content plans inside
  `/legalhub-os/`.
- After each task, update `CURRENT_STATE.md`, `TASK_LOG.md`, and
  `NEXT_STEPS.md`.

This folder must not interfere with the LegalHub CRM application. It is a
documentation and marketing workspace, not an app feature folder.
